# Identidade visual do Workoutly

A entrega Mobile mantém a paleta e a marca do projeto do grupo. `Colors.xaml` define os tokens de fundo, superfícies, contornos, texto e destaque. `Styles.xaml` usa esses tokens nos campos, cartões e botões. `MauiProgram.cs` registra os quatro pesos de Inter e ajusta os contornos dos campos nativos.

O fundo usa `Canvas` (`#0A0A0A`) e as ações principais usam `Accent` (`#C5F67A`). Ícone e splash têm valores de build no `.csproj`. As ilustrações do catálogo são recursos locais com atribuição em [THIRD-PARTY-NOTICES.md](../THIRD-PARTY-NOTICES.md).

As [capturas da entrega](mobile-final/Workoutly-Mobile-Relatorio.pdf) mostram as quatro telas com o tema atual. As referências antigas do Figma estão no histórico Git.
